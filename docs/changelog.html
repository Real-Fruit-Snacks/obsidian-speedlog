1.0.0September 2026
  • First release. Speed test against the nearest LibreSpeed server, a chosen one, or Cloudflare; Accurate, Balanced and Light profiles; four parallel streams and latency under load.
  • One note per run with numeric front matter, a results callout with per-label comparison, and a timeline of every step.
  • Summary.md with per-label medians, failed runs and the last 7 days, rewritten after every run.
  • Sidebar panel with live log, sparkline and recent runs; status bar; cancel; optional scheduling, off by default.
